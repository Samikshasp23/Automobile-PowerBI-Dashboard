# Automobile Power BI Dashboard

## 📌 Project Overview
This project showcases an interactive **Power BI dashboard** designed to analyze automobile sales, profit trends, and performance across models, manufacturers, countries, and time periods.  
The dashboard helps identify key business insights and supports data-driven decision-making.

---

## 🛠 Tools & Technologies
- Power BI Desktop  
- Power Query (Data Transformation)  
- DAX (Measures & KPIs)  
- Excel (Sample Dataset)

---

## 📊 Dashboard Highlights
- Total Sales by Model and Manufacturer
- Country-wise Sales Distribution
- Monthly and Year-wise Sales Trends
- Profit vs Sale Price Analysis
- KPI Cards, Gauge, Waterfall, Treemap & Map Visuals
- Interactive filters and slicers

---

## 📈 Key Insights
- United Kingdom contributes the highest share of total sales
- DB9 and XK are top-performing automobile models
- Sales show strong growth from 2012 to 2015
- December records peak monthly sales
- Premium manufacturers generate higher profit margins
